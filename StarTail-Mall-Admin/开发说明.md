# 星轨商城后台管理开发说明

## 定位

当前目录已从原 uni-admin 模板入口改造成独立 Vue3 + Vite 后台管理端。旧的 uni-admin 文件仍保留在目录中，作为后续迁移菜单、权限、统计和云端数据的参考。

## 运行

```bash
cd StarTail-Mall-Admin
npm install
npm run dev
```

默认地址：

```text
http://localhost:5173
```

也可以在仓库根目录运行：

```bash
npm run dev
```

## 当前实现

- `src/App.vue`：后台页面编排，负责模块切换、搜索、状态筛选和详情抽屉状态。
- `src/components/AppSidebar.vue`：左侧模块导航。
- `src/components/MetricGrid.vue`：经营指标卡片。
- `src/components/DataPanel.vue`：筛选区和数据表格。
- `src/components/DetailDrawer.vue`：行详情抽屉。
- `src/data/modules.js`：当前 mock 数据和模块配置，后续接真实接口时优先替换这里的数据来源。

## 后续迁移建议

1. 先接商品管理接口，确认后台与客户端商品数据模型一致。
2. 再接订单管理接口，区分支付状态、履约状态和售后状态。
3. 用户权限、管理员登录和审计日志应放到服务端校验，不依赖前端角色字段。
